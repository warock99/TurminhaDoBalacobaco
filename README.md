# Turminha do Balacobaco

Jogos para jogar com a galera, num celular só. Funciona sem internet e sem cadastro.

**Jogar:** https://warock99.github.io/TurminhaDoBalacobaco/

No Android, abra o link no Chrome e toque em **⋮ → Adicionar à tela inicial** para instalar como app.

## Jogos
- **Impostor** — todo mundo sabe a palavra secreta, menos o impostor. Descubram quem é!
- Em breve: jogo de números secretos e dicas.

## Para desenvolver
```bash
npm install
npm run dev
```
